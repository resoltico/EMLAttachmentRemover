EML Attachment Remover — prebuilt macOS application

Both editions require macOS 14 or later. Download arm64 for Apple Silicon or x86_64 for Intel. The main ZIP includes a private CPython runtime; the smaller ZIP with external-python in its name requires your own CPython 3.14. Swift, Xcode and personal code signing are not required.

1. Download the matching ZIP from the project's official GitHub Release, check its checksum/provenance, then extract it. Quit any previous EML Attachment Remover instance.
2. For the main bundled edition, copy EML Attachment Remover.app into ~/Applications in Finder. Create that folder inside your home folder if needed. Open the installed app in Finder. You do not install Python separately.
3. For the external-python edition, install CPython 3.14 first. For automatic installation and private interpreter selection, open Terminal in the extracted ZIP folder and run:
   EML_REMOVER_PYTHON=/absolute/path/to/python3.14 /bin/sh install.sh "EML Attachment Remover.app"
   Replace the placeholder with your actual interpreter path. Alternatively copy the app into ~/Applications and use runtime discovery.
4. The optional managed installer also works for the bundled edition without an external interpreter:
   /bin/sh install.sh "EML Attachment Remover.app"
   It uses the app's private interpreter, preserves runtime links and does not change an external-Python preference. Previous managed app bundles are retained in private application-support backups. The installer refuses a CPU mismatch or an update while the destination app is running.
5. This app is ad-hoc signed without Developer ID or notarization. If macOS blocks the internet download with an unidentified-developer or cannot-check-for-malicious-software warning, dismiss it with Done or OK, keeping the app.
6. Open System Settings > Privacy & Security, scroll to Security, and select Open Anyway for EML Attachment Remover. Authenticate if requested, then confirm Open in the additional warning. Attempt the app launch first; the exception normally appears only after a blocked launch. Managed-device policy may require administrator assistance or prohibit an exception.
7. Choose files or folders after the app opens, or select them in Finder and choose Services → Create EML Copies Without Attachments. The app must have been opened once to register its Finder service.

If no Open Anyway entry appears, check whether the app already opens. For a damaged or invalid signature, obtain a clean official download. Do not disable Gatekeeper globally, strip quarantine or re-sign release files as routine setup steps.

Updates: quit the app, verify and extract the new matching edition, then replace it in Finder or rerun its managed installation command. A new build may need app-specific macOS approval again. Do not change editions while a batch is running.

An external-python edition's missing-Python message is separate from Gatekeeper approval. Install/select CPython 3.14; CPython 3.15 is not a supported substitute. A bundled edition with a missing or damaged private runtime requires a fresh app download, not external runtime configuration.

Install the CLI separately from the wheel or invoke the standalone zipapp. Finder-action completion confirms launch; synchronous processing status comes from the CLI.

Apple's app-specific approval instructions: https://support.apple.com/102445

Finder Services: open the installed app once, select EML files or folders in Finder, then choose Services → Create EML Copies Without Attachments. If macOS asks Confirm Service, choose Run Service for your intended selection. This launch acknowledgment does not wait for processing; review the app’s report. The optional Shortcuts Quick Action is separate: in Shortcuts, create a shortcut that receives files and folders from Finder, enable Use as Quick Action, add Run Shell Script with input passed as arguments, and use /usr/bin/open -a "$HOME/Applications/EML Attachment Remover.app" -- "$@". No Show Content action is needed.
